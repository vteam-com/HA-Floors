# Home Layout Card

One card for the whole house: a floorplan per storey, live entity markers on top,
and a visual editor to place everything by clicking and dragging.

- Unlimited storeys with tab / pill / dropdown switching
- Any floorplan image — SVG, PNG, JPG or WebP — plus an optional dark-theme variant
- Markers as icon pucks, state badges, text labels, dots, or whole-room areas
- Rooms in an inline SVG can be tinted by entity state
- An "all storeys" isometric view that stacks the floors
- Pinch / scroll zoom and pan, tap / hold / double-tap actions
